Drag an encoder up or down. Values step to useful numbers; hold Shift, or drag with two fingers, for fine control. Scroll over it or use the arrow keys for smooth steps. Double-click resets it. Click the waveform to move the play position. Drop an audio file anywhere to load it. Space plays and stops. MATCH keeps the processed level equal to the original (K-weighted loudness) so bypass is a fair comparison. PRE -/+ steps through presets and A / B flips between two settings. LOAD takes one file or many (stems); NEXT steps through them. Export renders every loaded file at 8x oversampling at its own sample rate, matches loudness exactly (integrated LUFS), and saves 32-bit float WAVs in a .zip, named like the originals with _hf added.
